<p style="text-align: center;">This fully configurable mod makes enchanting and anvil use cost the same amount of EXP, regardless of your level. It removes Minecraft’s built-in penalty for leveling up, where higher levels require more XP but enchanting, and using the anvil still costs the same number of levels. This means high-level players end up spending significantly more total EXP for the same actions.</p>
<p style="text-align: center;">Flat EXP Costs mod features two selectable modes, which can be configured in the config file. The first mode calculates EXP costs as if you were exactly at the required level. For example, a level 30 enchantment always costs 306 XP, even if you are at a much higher level. The second mode just sets an exp price for one level.</p>

<summary><strong>Configuration</strong></summary>
<p>You can configure this mod either directly in-game or by editing the JSON file <code>config/consistentexpcost.json</code> in your profile folder.</p>
<center><p style="text-align: center;"><p style="text-align: center;"><b>use_minimal_exp_cost</b> - If set to true experience costs will be based on the minimal level required. If set to false the exp costs will be based on the value bellow</p></center>
<center><p style="text-align: center;"><p style="text-align: center;"><b>set_level_cost</b> - How much exp will be deducted for every level in the original cost</p></center>
</details>
